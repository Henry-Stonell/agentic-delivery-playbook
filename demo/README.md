# Demo

The plan review, working on real GitHub issues about a made-up app, so you can see it without anything from a real company. There's no running app: each issue stops at the go.

- [The app](app.md): a shared shopping list for a household.
- [The decision library](decisions.md): the decisions the reviewer checks every plan against.
- The demo issues: every issue with the `demo` label.
- [The reviewer](../reviewer/): the small plan reviewer that gives the verdicts.
- [The results](../docs/08-results.md): every run, right or wrong.

## How to follow one issue

1. The issue says what someone in the household wants.
2. A plan is posted as a comment. It starts with `## Plan`.
3. The plan reviewer answers from its own account with a verdict: fits, fits with questions, or doesn't fit.
4. Questions are answered in an updated plan, or I write `Decision: go` as the owner.

Nothing is built until there is a go.

## What's real and what's made up

The app and the requests are made up. The plans were written by an agent. The first plans on #1 and #3 have a mistake put in on purpose, to show what "doesn't fit" looks like. The verdicts are real answers from the reviewer, posted as they came, right or wrong.
