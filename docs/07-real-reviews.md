# 7. Two real reviews

Two real issues from the idea agent's first weeks. Names and details are removed. The verdicts are as they happened.

## A sidebar that forgets

In one app the sidebar can be collapsed, but it opens again after every reload. The request said it should remember. It counted as done "when it feels nicer to use".

| Round | Verdict | What the idea agent found |
|---|---|---|
| 1, the issue | Fits with questions | No priority label. "Feels nicer to use" can't be tested, so it suggested testable versions. |
| 2, the plan | Fits with questions | The plan said "we do it like another page". That page only remembers its state for one tab, so copying it would fail the test. It named the page that does it right. It also asked who tests it by hand. |

A plan that sounds right can still be wrong. The idea agent checks claims against the code, and one comment saved a rework.

## A "small" fix that took five rounds

Coloured status labels on several screens were hard to read: blue text on dark backgrounds. The plan was to use the pale label styles that already existed.

| Round | Verdict | What the idea agent found |
|---|---|---|
| 1 | Fits with questions | One claim about a screen was wrong. One label broke the design rule and wasn't covered. Other screens had the same problem. |
| 2 | Fits with questions | A needed change was planned for only some pages. Two labels would end up looking the same. |
| 3 | Fits with questions | One more label wasn't named. That's a design choice, so it asked me to decide. |
| 4 | Fits with questions | Two more pairs of labels would look the same. I accepted that, because the words tell them apart. |
| 5 | Fits | It checked the final list against the code. These were the only screens with the problem. |

The plan was right in principle, but every round found a screen or a label it had missed. **A human reviewer would probably have approved it in round one.**

In round 3 I first picked a new style, then changed my mind a few minutes later. The idea agent followed my latest decision. Design choices went to me, not to the agent.

Five rounds in one day is a lot for a readability fix. That's the cost of being thorough, and why someone has to decide when to stop. See [not reviewing forever](03-idea-agent.md#not-reviewing-forever).
